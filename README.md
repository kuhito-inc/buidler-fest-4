# Buidler Fest #4 — Osaka, Japan

Private working repository for the 2027 event identity, website, motion, and social assets.

## Status
Brand identity is **draft**, not approved. Previous AI-generated logo and website images are visual references, not reproducible vector masters.

## Structure
- `brand/guidelines/` — brand rules and approval status
- `brand/tokens/` — design tokens
- `brand/logos/` — approved vector logo masters (pending)
- `brand/illustrations/` — approved artwork (pending)
- `references/` — concept provenance and review notes
- `website/`, `motion/`, `social/` — downstream production

Never redraw or regenerate an approved logo. Reuse the exact master asset.
